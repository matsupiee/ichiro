# 作成後に友達へチェックを依頼する

> ステータス: チェック者の設定・依頼リンクの共有と承認を実装済み。友達による達成の判定画面は未実装。

## ストーリー

ログイン中のユーザーとして、まずコミットメントを宣言し、必要なときだけ友達にチェックを依頼したい。
依頼リンクを送るか、すでに頼んでいる友達を選ぶことで、作成時の入力を増やさずにチェック者を決めたい。

## 動作確認の手順

iOS Simulator または実機のネイティブアプリだけで確認する。Web版やブラウザは使わない。
`bun run db:seed -- --url file:/絶対パス/対象.sqlite --skip-migrations` で Alchemy が移行済みのローカル D1 にデモデータを投入する。
空の SQLite ファイルには `--skip-migrations` を付けない。
demo@ichiro.app / password123 でログインする。「体づくり」は tanaka に依頼済み、「禁煙」はリンク発行済み、「広東語マスター」は自分で判定する設定。

1. コミットメントを作成する。
   - 作成フォームにはチェック者の入力欄がない。自分で判定する設定で保存される。
   - 「宣言したワン！」のお祝い画面が表示され、モーダルは自動では開かない。
   - → [コミットメントを作成できる](./create-commitment.md)
2. お祝い画面の「ホームに戻る」を押す。
   - 自分で判定する設定のまま一覧に戻る。
3. もう一件作成し、お祝い画面で「チェックを友達に依頼する」を押す。
   - 依頼モーダルが開き、「自分で判定する」「依頼リンクを共有」「友達から選ぶ」を選べる。
   - 閉じただけではチェック者は変わらず、お祝い画面に戻る。
4. 「依頼リンクを共有」を押す。
   - iPhoneの共有シートが開き、メッセージとアプリ内の依頼画面へのリンクが入る。
   - SNSなどの共有先を選べる。キャンセルしても作成済みのコミットメントは残る。
   - リンクの発行だけではチェック者は変わらない。再共有には同じ未承認リンクを使う。
5. ichiro が入っている端末で、受け取ったリンクを開く。
   - アプリ内に依頼画面が開く。未ログインならログインを促し、ログイン後に同じ依頼に戻る。
   - 依頼主の名前・目標・内容・終了日が表示される。
   - 「チェックを引き受ける」を押すとチェック者として設定される。
   - 自分の依頼は引き受けられない。一度引き受けられたリンクは再利用できない。
6. 依頼主に戻り、別のコミットメントで「友達から選ぶ」を押す。
   - 他のコミットメントでチェック者になっている友達だけが、重複せずに表示される。
   - 名前を押すと、その友達がチェック者になる。
   - シート左上の左向きchevronを押すと依頼方法に戻る。一覧の下に戻るボタンは表示しない。右上の閉じるボタンはシートを閉じる。
   - 候補がいない場合は一覧に移動せず、「友達がいません。依頼リンクを共有してみましょう。」というトーストが約4秒間表示される。
   - 読み込みに失敗した場合は、友達がいない場合と区別したエラートーストが表示され、もう一度押して再試行できる。
7. コミットメントの編集シートを開き、「チェック者」の欄を押す。
   - 同じ依頼モーダルでチェック者を変更できる。チェック者の変更はその場で保存される。
   - 友達を選択して閉じた後にもう一度開いても、最初の描画から依頼方法を表示する。前回の友達一覧は一瞬も表示しない。友達一覧を右上の閉じるボタンで閉じた場合も同じ。
   - 「自分で判定する」を押すと自分に戻り、以前の依頼リンクは無効になる。
   - 別の友達を選んだ場合も、以前の依頼リンクで上書きできない。

## データの持ち方

- 作成APIはチェック者を入力として受け取らず、`commitment.checker` を `self` で保存する。
- `checker_user_id` は承認済みまたは既知の友達から選んだユーザーのID。
  - 友達候補は、同じ持ち主の別のコミットメントでチェック者になっているユーザーから取得する。
  - 任意のユーザーIDを指定して他人をチェック者にすることはできない。
- `share_token` は未承認の依頼にだけ使う推測困難なトークン。
  - 承認されるまで今のチェック者を維持する。承認時に一度だけ消費する。
  - 自分または別の友達への変更時に失効する。旧Web閲覧用リンクも移行で失効する。
- 依頼内容の取得と承認にはログインが必要。メール送信・メールアドレス入力・再送機能は使わない。
