# チェック役の友達に招待メールが届く

> ステータス: 実装済み（友達の側でチェックする画面は未実装）

## ストーリー

ログイン中のユーザーとして、チェック役に選んだ友達へ、自分の宣言を知らせたい。
友達が内容を知っていれば、見守ってもらえてサボりにくくなるから。
友達がまだ ichiro を使っていなければ、会員登録もお願いしたい。

## 動作確認の手順

`bun run db:seed` でデモデータを入れ、demo@ichiro.app / password123 でログインしておく。
デモデータには、登録ずみの友達 matsukiyo@example.com と、未登録の友達 mom@example.com がいる。

サーバーに `RESEND_API_KEY` がないときは、メールは送らずにサーバーのログへ出る。
実際に届くかを確かめるときは、Resend の API キーと、Resend で認証したドメインの `MAIL_FROM` を設定する。

1. メインページの右下のプラスボタンを押し、目標とコミット内容を入れる。
   - → [コミットメントを作成できる](./create-commitment.md)
2. 「誰にチェックしてもらう？」で「友達」を選び、まだ登録していないメールアドレス（たとえば new-friend@example.com）を入れて「宣言する」を押す。
   - コミットメントが作られ、お祝い画面が出る。
   - 友達に「hiromuさんから、ichiro への招待が届きました」という件名のメールが届く。
   - 本文には、誘った人の名前とメールアドレス、目標・コミット内容・報告の頻度・期間（罰金ありなら金額も）が入る。
   - 本文の最後に、そのメールアドレスで会員登録してほしいというお願いが入る。
3. もう一度作成ページを開き、友達に matsukiyo@example.com（大文字まじりでもよい）を入れて宣言する。
   - 件名が「hiromuさんから、チェック役のお願いが届きました」になり、会員登録のお願いは入らない。
4. 友達に自分のメールアドレス（demo@ichiro.app）を入れて宣言する。
   - 「自分のメールアドレスは指定できません」と表示され、作成されない。
5. 「自分」を選んで宣言する。
   - 招待メールは送られない。
6. メインページで「体づくり」のカードを押す。
   - 友達のメールアドレスの下に「チェックのお願い」「◯/◯ に送信ずみ」と「再送する」ボタンが出る。
   - 「禁煙」では「会員登録のお願い」になる。
   - 「広東語マスター」は自分でチェックするので、どちらも出ない。
7. 「体づくり」で「再送する」を押す。
   - シードや前回の送信から1分たっていなければ、「少し時間をおいてから再送してください」のアラートが出て送られない。
   - 1分たっていれば、同じ友達にもう一度メールが届き、日付が今日になる。
8. 「体づくり」の友達のメールアドレスを別のアドレスに変えて「変更を保存」を押す。
   - 新しいアドレスに招待メールが届く。
   - 入力を変えているあいだは、前のアドレスの送信状況は出ない。
9. 目標だけを変えて「変更を保存」を押す。
   - 友達が同じままなので、招待メールは送られない。
10. メールを送れない状態（API キーがまちがっているなど）で、友達にチェックしてもらうコミットメントを作る。
    - コミットメントは作られ、お祝い画面のあとに「招待メールを送れませんでした」のアラートが出る。
    - 詳細ページでは「送れませんでした」と出て、すぐに「再送する」で送り直せる。

## データの持ち方

- 送った招待メールは `invitation` テーブルに1通ずつ持つ。再送するたびに行が増える。
  - `commitment_id` でどのコミットメントの招待かを決める。コミットメントを消すといっしょに消える。
  - `email` は送った先。友達のメールアドレスは小文字にそろえて保存する。
  - `kind` は `registered`（登録ずみの友達へのチェックのお願い）か `sign_up`（未登録の友達への会員登録のお願い）。送るときに `user` テーブルにそのメールアドレスがあるかで決める。
  - `status` は `sent` か `failed`。送れなくてもコミットメントの作成や変更は取り消さない。
  - `message_id` は Resend が返すメールの ID。送れなかったときは null。
- 詳細ページに出すのは、いまの友達のメールアドレスに最後に送った招待だけ。
- 招待メールを送るのは次のときだけ。
  - 友達にチェックしてもらうコミットメントを作ったとき。
  - 変更で、チェック役が自分から友達に変わったか、友達のメールアドレスが変わったとき。
  - 「再送する」を押したとき。前回の送信に成功していたら、1分あけないと送れない。
- メールは Resend で送る。サーバーの `RESEND_API_KEY` と `MAIL_FROM` を使う。
  - `RESEND_API_KEY` がないときは、送る代わりにサーバーのログへ出す。

- メールの本文は `packages/api/src/shared/invitation/build-invitation-email.test.ts`
- メールの本文は同じファイルの「招待メールの本文」
