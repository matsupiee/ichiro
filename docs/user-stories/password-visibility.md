# 入力したパスワードを表示して確認する

> ステータス: 実装済み

## ストーリー

パスワードを入力する利用者として、入力欄の右端のボタンで文字を確認し、入力間違いを防ぎたい。

## 動作確認の手順

1. ブラウザで新規登録画面（http://localhost:3000/app/sign-up）を開き、パスワードを入力する。
   - 最初は文字が伏せられる。右端に目のボタン（「パスワードを表示」）が表示される。
   - 新規登録とパスワード再設定の欄は新しいパスワード（`autocomplete="new-password"`）、ログインの欄は保存済みのパスワード（`autocomplete="current-password"`）として、ブラウザのパスワード管理を使える。
2. 「パスワードを表示」ボタンを押す。
   - 同じ入力値が平文で表示される。ボタン名は「パスワードを隠す」に変わる。
3. 続きを入力して「パスワードを隠す」を押す。
   - 入力値を保持したまま、再び伏せ字になる。
4. ログイン画面とパスワード再設定画面（認証コードと新しいパスワードを入力する段階）でも同じ操作をする。
   - 各画面は伏せ字から始まる。切り替えた後も入力内容で送信できる。
   - → [パスワードを忘れたときに再設定する](./reset-password.md)

## データの持ち方

- 表示状態は各入力欄（`apps/web/src/components/ui.tsx` の `PasswordField`）のローカル状態のみで管理する。DB やブラウザのストレージへ保存しない。
- パスワードの値を URL やログへ出力しない。

## 対応するテスト

- `apps/web/e2e/onboarding.spec.ts`：新規登録・ログイン画面での表示の切り替え。
- `apps/web/e2e/password-reset.spec.ts`：パスワード再設定画面での表示の切り替え。
- seed は [パスワード再設定](./reset-password.md) と共通。
