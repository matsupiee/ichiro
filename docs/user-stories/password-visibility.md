# 入力したパスワードを表示して確認する

> ステータス: 実装済み

## ストーリー

パスワードを入力する利用者として、入力欄の右端のボタンで文字を確認し、入力間違いを防ぎたい。

## 動作確認の手順

1. iOS Simulator または実機で新規登録画面を開き、パスワードを入力する。
   - 最初は文字が伏せられる。右端に目のボタンが表示される。
   - iOSの新規登録・再設定では、入力の置換を防ぐため新規パスワードの自動補完を使わない。ログイン時の自動補完は維持する。
2. 「パスワードを表示」ボタンを押す。
   - 同じ入力値が平文で表示される。ボタン名は「パスワードを隠す」に変わる。
3. 続きを入力して「パスワードを隠す」を押す。
   - 入力値を保持したまま、再び伏せ字になる。
4. ログイン画面とパスワード再設定画面でも同じ操作をする。
   - 各画面は非表示から始まる。切り替えた後も入力内容で送信できる。
   - → [パスワードを再設定する](./reset-password.md)

## データの持ち方

- 表示状態は各入力欄のローカル状態のみで管理する。DBや端末ストレージへ保存しない。
- パスワードの値をURLやログへ出力しない。

## 対応するテスト

- `.maestro/password-visibility.yaml`
- `.maestro/password-reset-request.yaml` と `.maestro/password-reset-confirm.yaml`
- seedは [パスワード再設定](./reset-password.md) と共通。
