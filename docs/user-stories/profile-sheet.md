# プロフィールのシートでアカウントを管理できる

> ステータス: 実装済み（プロフィール写真はこの端末にだけ保存。支払い情報とメニューの行は表示のみ）

## ストーリー

ログイン中のユーザーとして、写真や名前を変えたり、ログアウトしたりしたい。
友達にチェックしてもらうときに、自分だと分かってもらえるから。

## 動作確認の手順

1. メインページの右上のプロフィールアイコンを押す。
   - 下から「アカウント」のシートが開く。
   - 右上の ✕ か、シートの外側を押すと閉じる。
2. 「プロフィール写真」の行を押す。
   - 「写真を選択」「削除」のポップアップが出る。
   - 「写真を選択」を押すと写真ライブラリが開き、選んだ写真が正方形に切り抜かれて、シートとメインページのアイコンに出る。
   - アプリを開き直しても写真は残る。
   - 「削除」を押すと灰色の丸に戻る。
3. 「名前」の行を押す。
   - 「名前を編集」のモーダルが開き、今の名前が入っている。
   - 名前を変えて「保存」を押すと、シートの名前が変わる。
   - 空のまま保存するとエラーが表示され、変わらない。
   - 「キャンセル」を押すと、変えずに閉じる。
4. 「支払い情報」とメニュー（利用規約・プライバシーポリシー・問い合わせ・報告）の行を見る。
   - 行は表示されるが、押しても何も開かない（未実装）。
5. 「ログアウト」を押す。
   - シートが閉じ、オンボーディング画面に戻る。
   - → [アプリを開いたら新規登録とログインを選べる](./onboarding.md)

## データの持ち方

- 名前は `user.name`。Better Auth の `updateUser` で書きかえる。
- プロフィール写真は、画像のアップロード先がまだないので、端末の Secure Store に写真の場所だけを保存する（キーは `ichiro.avatar.<ユーザーID>`）。
  - ほかの端末には出ない。アップロード先ができたら `user.image` に置き換える。

## 対応するテスト

- 名前の変更とログアウトは Better Auth に任せており、API のテストはない。
