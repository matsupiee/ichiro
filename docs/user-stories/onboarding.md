# アプリを開いたら新規登録とログインを選べる

> ステータス: 実装済み

## ストーリー

未ログインのユーザーとして、アプリを開いたときに「新規登録」と「ログイン」のどちらかを選びたい。
どちらを選んだのか分かる専用の画面で入力したいから。

## 動作確認の手順

1. 未ログインの状態でアプリを開く。
   - オンボーディング画面（ワンちゃん + ロゴ + 説明 + 「アカウントを作る」「ログイン」ボタン）が表示される。
   - メインページ・コミットメントの画面のいずれにも到達できない。
   - ワンちゃんを押すと、軽くバイブして少しのあいだ跳ねる。
2. 「アカウントを作る」を押す。
   - 新規登録画面（名前・メールアドレス・パスワード）に遷移する。
   - ログインのフォームは同時に表示されない。
   - 空のまま「登録する」を押すと「名前を入力してください」と表示され、登録されない。
3. 「ログイン」を押す。
   - ログイン画面（メールアドレス・パスワード）に遷移する。
   - 新規登録のフォームは同時に表示されない。
   - まちがったパスワードでは、エラーが表示されてログインできない。
4. 各画面の下部のリンクを押す。
   - もう一方の画面に切り替わる。
5. 各画面のヘッダーの戻るボタンを押す。
   - オンボーディング画面に戻る。
6. 登録またはログインする。
   - メインページに遷移する。
   - → [メインページでコミットメントを一覧できる](./commitment-list.md)
7. 右上のプロフィールアイコンを押してシートを開き、「ログアウト」を押す。
   - オンボーディング画面に戻る。
   - → [プロフィールのシートでアカウントを管理できる](./profile-sheet.md)

## データの持ち方

- 認証は Better Auth のメールアドレス + パスワード。`user`・`account`・`session` テーブルを使う。
  - 画面の切り替えはセッションの有無で決まる。`app/_layout.tsx` の `Stack.Protected` が、ログイン中は `(app)`、未ログインは `(auth)` の画面だけを開けるようにする。

## 対応するテスト

- 認証そのものは Better Auth に任せており、API のテストはない。
- ログインしていないと API を呼べないことは `packages/api/src/routers/commitment.test.ts` の「ログインしていないと一覧できない」で確かめる。
