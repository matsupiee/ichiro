# アプリを開いたら新規登録とログインを選べる

> ステータス: 実装済み

## ストーリー

未ログインのユーザーとして、アプリを開いたときに「新規登録」と「ログイン」のどちらかを選びたい。
どちらを選んだのか分かる専用の画面で入力したいから。

## 動作確認の手順

1. 未ログインの状態でアプリを開く。
   - オンボーディング画面（アプリ名 + 説明 + 「新規登録」「ログイン」ボタン）が表示される。
   - タブ・やりたいことの詳細のいずれの画面にも到達できない。
2. 「新規登録」を押す。
   - 新規登録画面（名前・メールアドレス・パスワード）に遷移する。
   - ログインのフォームは同時に表示されない。
3. 「ログイン」を押す。
   - ログイン画面（メールアドレス・パスワード）に遷移する。
   - 新規登録のフォームは同時に表示されない。
4. 各画面の下部のリンクを押す。
   - もう一方の画面に切り替わる。
5. 各画面のヘッダーの「戻る」を押す。
   - オンボーディング画面に戻る。
6. 登録またはログインする。
   - メインページに遷移する
7. プロフィール右上のプロフィールアイコンを押すとシートが開き、サインアウトボタンを押すとサインアウトする。
   - オンボーディング画面に戻る。
