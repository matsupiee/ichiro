# 現在と変更先のメールアドレスを確認して変更できる

> ステータス: 実装済み。

## ストーリー

ログイン中のユーザーとして、現在のアドレスと新しいアドレスに届くコードでメールアドレスを変更したい。
他人のアドレスを誤って登録せず、受信できるアドレスを使い続けるため。

## 動作確認の手順

[認証メールの開発手順](../development/auth-email.md)でメールの受信環境を準備する。

1. プロフィールシートの「メールアドレス」を押す。
   - 現在のアドレスが表示され、新しいアドレスを入力できる。
2. 新しいアドレスを入力して「現在のアドレスにコードを送る」を押す。
   - 現在のアドレスへ6桁のコードが届く。
3. 現在のアドレスに届いたコードを入力する。
   - 正しい場合だけ新しいアドレスへの確認に進む。
4. 新しいアドレスへ届いたコードを入力する。
   - 正しいコードで変更が完了し、新しいアドレスが表示される。
   - 別のアドレス宛て・期限切れ・使用済みのコードは使えない。
   - 完了するまで登録アドレスは変わらず、途中で戻っても旧アドレスでログインできる。
5. ログアウトし、新しいアドレスと既存のパスワードでログインする。
   - ログインでき、旧アドレスではログインできない。

## データの持ち方

- 変更完了時に `user.email` を更新し、`emailVerified` を維持する。
- `verification` に現在のアドレスの確認と、変更元・変更先の組に対応するコードを保存する。
  - 再送・有効期限・試行回数の制限は登録時と同じ。やり直す場合は現在のアドレスの確認から再開する。
