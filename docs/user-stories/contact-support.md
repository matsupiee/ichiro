# メールで問い合わせ・報告できる

> ステータス: 実装済み。

## ストーリー

ログイン中のユーザーとして、アカウント画面から運営へ問い合わせや不具合の報告を送りたい。
困ったときに、送付先を調べずに相談できるようにするため。

## 動作確認の手順

1. 既存の `packages/db/src/seed/run.ts` のコマンド `bun run db:seed -- --url file:/絶対パス/対象.sqlite --skip-migrations` で確認用ユーザーを作成する。
   - 開発サーバーのローカル D1 を `--url` に指定する。
2. `bun run dev:server` を起動し、ブラウザで http://localhost:3000/app を開いてデモユーザーでログインする。
3. 右上のアカウントのボタンからアカウント画面を開き、「問い合わせ・報告」を見る。
   - リンク先は `mailto:btq32jh@icloud.com` で、件名「ichiro 問い合わせ・報告」が付いている。
   - 行の下に「メールアプリが開かない場合は btq32jh@icloud.com 宛にお送りください。」と表示される。
4. 「問い合わせ・報告」を押す。
   - メールアプリが設定されている環境では、宛先 `btq32jh@icloud.com`、件名「ichiro 問い合わせ・報告」のメール作成画面が開く。
   - 本文に問い合わせや報告の情報を入力できる。送信は利用者がメールアプリで行う。
   - アカウント情報や支払い情報は自動で本文に追加されない。
5. メールの作成をやめてブラウザに戻る。
   - アカウント画面を引き続き操作でき、再度メール作成を開ける。
6. メールアプリが設定されていない環境でも画面を見る。
   - 行の下の案内で送付先 `btq32jh@icloud.com` を確認できる。
7. `bun run test` で既存ストーリーの回帰テストを実行する。

## データの持ち方

- 宛先と件名は `apps/web/src/routes/app/_member/account.tsx` に持ち、`mailto:` のリンクでブラウザからメールアプリに渡す。
- 新しい API や DB テーブルは追加しない。確認用データには既存の seed コマンドを使う。
- 特定商取引法に基づく表記と同じ問い合わせ先を使用する。利用規約の問い合わせ先の参照と、プライバシーポリシーの問い合わせ対応の利用目的を維持する。

## 対応するテスト

- `apps/web/e2e/account.spec.ts`：「問い合わせ・報告」の宛先と件名、メールアプリが開かない場合の案内。
- メールアプリへの受け渡しは、メールアプリを設定したブラウザで手動で確認する。
- 問い合わせ先と法定文書の案内は `apps/web/src/server/public-page.test.ts` で確認する。
- 既存ストーリーの回帰確認は `bun run test` で実行する。
