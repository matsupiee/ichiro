# 必要なときだけ罰金の履歴を開く

> ステータス: 実装済み

## ストーリー

コミットメントに取り組むユーザーとして、詳細画面では報告や設定に集中し、罰金の合計と履歴は必要なときに開きたい。

## 動作確認の手順

既存の `packages/db/src/seed/run.ts` を使い、`bun run db:seed -- --url file:/絶対パス/対象.sqlite --skip-migrations` でローカルのデモデータを作る。demo@ichiro.app / password123 でネイティブアプリにログインする。

1. 罰金履歴のある広東語のコミットメントの詳細を開く。
   - 連続達成の下には「これまでの罰金」と矢印の1行だけが出る。合計・回数・履歴は出ない。
2. コミット内容を編集し、保存せず「これまでの罰金」を押す。
   - シートが開き、合計・回数・日付・金額・徴収状況が見られる。履歴が長い場合はスクロールできる。
   - 徴収に失敗した行には理由も出る。
3. 戻るボタンでシートを閉じる。
   - 詳細画面に戻り、編集中のコミット内容が保持される。
   - 再び開いて下にスワイプしても閉じられ、もう一度開ける。
4. 詳細画面を保存せず閉じ、罰金履歴のない「禁煙する」の詳細で「これまでの罰金」を押す。
   - シートに ¥0、0回と「まだ罰金はないワン。この調子でつづけよう。」が出る。
5. 罰金未設定かつ履歴のないコミットメントの詳細を開く。
   - 「これまでの罰金」の導線が出ない。
   - 過去の履歴があれば、現在の罰金設定がオフでも導線から確認できる。

## データの持ち方

- 既存のコミットメント詳細 API の `penaltyTotal` と `penalties` を使う。
- 開閉状態は画面内に持ち、編集フォームの値は変更しない。
- 徴収条件、支払い、個人情報の扱いは変更しない。利用規約・プライバシーポリシー・特定商取引法に基づく表記の変更は不要。

- `bun run test` で全ストーリーに対応する既存の回帰テストを実行する。
