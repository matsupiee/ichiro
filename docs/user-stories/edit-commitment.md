# コミットメントの詳細を見て、途中で設定を変えられる

> ステータス: 実装済み

## ストーリー

ログイン中のユーザーとして、コミットメントの記録を確かめ、必要なら期間中でも設定を変えたい。
続けるうちに無理のない頻度や金額が分かってくるから。

## 動作確認の手順

リポジトリのルートで `bun run dev:server` を起動し、`bun run --cwd packages/db db:seed:e2e` でデモデータを入れる。
ブラウザで http://localhost:3000/app を開き、demo@ichiro.app / password123 でログインしておく。

1. メインページで「週3でジムに行って、筋トレ45分と有酸素運動20分をやる」のカードを押す。
   - 「コミットメント詳細」ページ（`/app/commitments/<id>`）が開く。
   - 上のカードに連続達成の日数と、今週（月〜日）の7つの丸が出る。報告した日は水色、それ以外は灰色。
   - 今日が報告日で未報告なら「今日の達成を報告する」ボタン、報告ずみなら「今日は報告ずみ　えらいワン」が出る。今日が報告日でなければどちらも出ない。
   - → [今日の達成を報告すると、ワンちゃんが祝福してくれる](./report-achievement.md)
   - 罰金を設定しているなら、その下に「これまでの罰金」の1行の導線が出て、押すと履歴のシートが開く。デモデータの「週3でジムに行って、筋トレ45分と有酸素運動20分をやる」は罰金の履歴がないので、シート内は ¥0 と「まだ罰金はないワン。この調子でつづけよう。」になる。
   - → [必要なときだけ罰金の履歴を開く](./view-penalty-history.md)
2. 下のフォームを最下部までスクロールし、先頭へ戻す。
   - 「コミットメント詳細」のタイトルと戻るボタンは画面の上に固定され、本文だけがスクロールする。
   - 最下部の「変更を保存」まで表示できる。
   - 作成ページと同じ項目（コミット内容・頻度・いつまで・罰金・支払い方法）に、今の設定が入っている。
   - コミット内容は長い文章が折り返されて表示される。候補は出ない。
   - 編集中に Enter キーを押すと、改行を追加せず入力欄から抜ける。入力内容は保持され、変更は「変更を保存」を押すまで保存されない。
   - チェック者の選択や招待リンクの発行は表示されない。
3. コミット内容や罰金の金額を変えて「変更を保存」を押す。
   - 罰金の金額の下に「変更した金額と支払い方法は、今日の報告分から使われます。」と出る。
   - メインページに戻り、変えた内容が一覧に出る。
   - もう一度開くと、変えた内容が残っている。ブラウザで再読み込みしても同じ。
   - 連続達成と今週の記録は変わらない。
4. 終了日を開始日より前にしようとする。
   - 日付入力で開始日より前の日付は選べない。
5. 左上の戻るボタンを押す。
   - 保存せずにメインページに戻る。

## データの持ち方

- 変更は `commitment` テーブルの同じ行を書きかえる。
  - `start_date` と `user_id` は変えない。
  - 報告の記録（`report` テーブル）はそのまま残る。
  - 保存する前に、締め切りを過ぎた分の罰金を変更前の設定で精算する。そのうえで `settled_through` を昨日にするので、新しい設定は今日の分から使われる。
  - `time_zone` は変更したブラウザのタイムゾーンに書きかえる。
- 編集用の詳細と報告は持ち主だけが利用できる。

## 対応するテスト

- `apps/web/e2e/commitments.spec.ts`：連続達成と今週の記録、チェック者や招待の項目がないこと、日付の下限、罰金の履歴を開いて閉じても編集中の内容が残ること、変更の保存と再表示。
