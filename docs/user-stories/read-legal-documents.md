# アプリ内で利用条件と個人情報の取り扱いを確認できる

> ステータス: 実装済み。

## ストーリー

アプリの利用を検討している人や利用中の人として、利用規約、特定商取引法に基づく表記、プライバシーポリシーをアプリ内で確認したい。
登録前や利用中に、請求条件と個人情報の取り扱いを読めるようにするため。

## 動作確認の手順

1. iOS Simulator または実機でネイティブアプリを起動する。
   - ログイン前の案内画面に3文書のリンクが表示される。
2. 各リンクを開く。
   - `expo-web-browser` のアプリ内ブラウザー に対応する文書の本文が表示され、末尾までスクロールできる。
   - 「閉じる」で元の画面に戻れる。
   - ブラウザー標準の戻る・再読み込み操作を使える。
3. ログインし、右上のプロフィールからアカウント画面を開く。
   - 3文書を同様に開ける。ブラウザーを閉じるとアカウント画面に戻れる。
   - → [サービス紹介](./view-service-introduction.md)
4. `bun run test` で既存ストーリーの回帰テストを実行する。

## データの持ち方

- `apps/native/lib/legal-pages.ts` に文書の識別子と名称を持つ。
  - 本文はサーバーの既存の `/terms`、`/commerce`、`/privacy` を表示する。
  - 接続先はアプリの `EXPO_PUBLIC_SERVER_URL` に従う。
- 新しい API や DB テーブルは追加しない。
  - ログイン前の確認には seed は不要。
  - ログイン後の確認には既存の `packages/db/src/seed/public-page.ts` の撮影用アカウントを使える。

## 対応するテスト

- `apps/server/src/public-page.test.ts` で3文書の配信を確認する。
- アプリ内ブラウザーの表示と開閉はネイティブで確認する。
- 既存ストーリーの回帰確認は `bun run test` で実行する。
