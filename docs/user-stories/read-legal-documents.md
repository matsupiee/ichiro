# アプリ内で利用条件と個人情報の取り扱いを確認できる

> ステータス: 実装済み。

## ストーリー

アプリの利用を検討している人や利用中の人として、利用規約、特定商取引法に基づく表記、プライバシーポリシーを確認したい。
登録前や利用中に、請求条件と個人情報の取り扱いを読めるようにするため。

## 動作確認の手順

`bun run dev:server` を起動しておく。

1. 未ログインのブラウザで http://localhost:3000/ を開く。
   - 紹介ページのフッターに3文書（利用規約・プライバシーポリシー・特定商取引法に基づく表記）のリンクが表示される。
   - → [サービス紹介](./view-service-introduction.md)
2. 各リンクを開く。
   - `/terms`、`/privacy`、`/commerce` に対応する文書の本文が表示され、末尾までスクロールできる。
   - プライバシーポリシーに通常データの削除期限30日、ログ90日、問い合わせ1年、税務上必要な取引記録の原則7年と起算日、削除請求窓口、国外での取扱いが表示される。
   - 利用規約・特商法表記に追加認証が必要な報告日分の自動請求停止が表示される。
   - ブラウザの戻る・再読み込みの操作を使える。
3. http://localhost:3000/app/sign-up を開く。
   - 「登録する」の直前の案内から、利用規約とプライバシーポリシーを別のタブで開ける。
   - → [利用条件を確認して新規登録する](./sign-up-consent.md)
4. ログインし、右上のアカウントのボタンからアカウント画面を開く。
   - 3文書の行を押すと、それぞれ別のタブで開く。タブを閉じるとアカウント画面に戻れる。
   - → [アカウント画面でアカウントを管理できる](./profile-sheet.md)
5. `bun run test` で既存ストーリーの回帰テストを実行する。

## データの持ち方

- 本文はサーバーの `/terms`、`/commerce`、`/privacy` が JavaScript なしの HTML で配信する。文面は `apps/web/src/server/site/legal.ts` に持つ。
  - アプリの画面と同じオリジンから配信する。
- アカウント画面の3文書の行は `apps/web/src/routes/app/_member/account.tsx` の `legalPages` に文書のパスと名称を持ち、`target="_blank"` のリンクで開く。
- 新しい API や DB テーブルは追加しない。
  - ログイン前の確認には seed は不要。
  - ログイン後の確認には既存の `packages/db/src/seed/public-page.ts` の撮影用アカウントを使える。

## 対応するテスト

- `apps/web/src/server/public-page.test.ts` で3文書の配信を確認する。
- `apps/web/e2e/public-site.spec.ts`：紹介ページから3文書を開く。
- `apps/web/e2e/account.spec.ts`：アカウント画面の3文書の行が別のタブで開く。
- 既存ストーリーの回帰確認は `bun run test` で実行する。

保存期間の方針と、まだ自動化していない削除運用は [個人情報の保存期間と削除対応](../development/privacy-retention.md) を参照する。
