# ブランドカラーで主要な操作を見分ける

> ステータス: 実装済み

## ストーリー

アプリ利用者として、ロゴと主要な操作に同じグラデーションが使われていてほしい。
画面を移動しても、操作するボタンと達成済みの状態を見つけやすくなるから。

## 動作確認の手順

移行済みのローカルDBでは、既存の `packages/db/src/seed/run.ts` を使い、`bun run db:seed -- --url file:/ローカルDBの絶対パス --skip-migrations` でデモデータを作る。

1. iOS Simulator または実機でアプリを起動する。
   - 未ログインの開始画面で、ロゴと「アカウントを作る」に左から赤・ピンク・紫のグラデーションが表示される。
2. デモアカウントでログインしてホームを開く。
   - ロゴ、今日の報告のマーク、達成済みマーク、追加ボタンに共通の配色が表示される。
3. 追加ボタンを押して作成画面を開く。
   - 曜日ごと・月の特定の日を選ぶと、選択済みの曜日・日付にグラデーションが表示される。
   - 未選択と区別でき、選択を解除できる。
4. コミット内容を入力して「宣言する」を押す。
   - ボタンの文字が読め、作成とお祝い画面の終了ができる。
   - 無効なボタンは薄く表示され、押せない。
5. 詳細から編集を保存し、今日の達成を報告する。
   - 保存と報告を操作でき、達成済みの丸と今週の記録にグラデーションが表示される。
   - → [自分で達成をチェックする](./self-check.md)
6. アカウント画面で名前を編集する。
   - 保存ボタンにも同じ配色が表示され、保存できる。

## データの持ち方

- 色は `apps/native/lib/theme.ts` の `brandGradient` で共通管理する。
  - DB・API・保存形式は変更しない。既存のデモデータ作成コマンドを利用する。
- 表示の変更のみで、料金・契約・個人情報の扱いは変更しない。
  - 利用規約・プライバシーポリシー・特定商取引法に基づく表記の変更は不要。

## 対応するテスト

- iOS Simulator でロゴとボタンの描画、曜日・日付の選択を確認する。
- `.maestro/self-check.yaml`：作成・編集保存・達成報告。
- `.maestro/report-confirmation.yaml`：報告のキャンセルと確定。
- `.maestro/retired-invite.yaml`：旧共有リンクからホームへ戻る操作。
- `bun run test --force`：全ストーリーに対応する既存API・サーバー・環境設定の回帰テスト。
