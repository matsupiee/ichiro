# 利用条件を確認して新規登録する

> ステータス: 実装済み。

## ストーリー

新しく利用する人として、登録前に利用規約とプライバシーポリシーを読み、登録操作が同意を意味することを確認して登録したい。

## 動作確認の手順

1. 未ログインの iOS Simulator または実機で新規登録画面を開く。
   - 「登録する」の直前に「『登録する』を押すと、利用規約およびプライバシーポリシーに同意したものとみなします。」という案内が表示される。
   - 文書名は下線付きのリンクで表示される。
2. 名前を入力してから、利用規約とプライバシーポリシーをそれぞれ開いて閉じる。
   - 対応する本文をアプリ内で読める。
   - 閉じると新規登録画面へ戻り、入力内容が保持される。
   - 文書を読むだけでは登録されない。
   - → [利用条件を確認する](./read-legal-documents.md)
3. 登録ボタンから登録を進める。
   - 既存の入力チェックとメール確認へ進む導線が維持される。
   - キーボードから送信する場合も同じ登録処理を行う。
   - → [メールアドレスの確認](./verify-email.md)
4. ログイン画面に切り替える。
   - 新規登録の同意案内は表示されない。

## データの持ち方

- 登録操作に対する案内を新規登録フォームに表示する。
- 文書は既存の `openLegalPage` を使用して `/terms` と `/privacy` を開く。
- 同意日時・文書バージョンなどの新しい保存項目や API は追加しない。
- 未ログインで確認できるため、このストーリー専用の seed は不要。
  - 登録済みユーザーでの回帰確認には `packages/db/src/seed/email-verification.ts` の既存コマンドを使う。
- 利用規約・プライバシーポリシー・特定商取引法に基づく表記を確認した。取得情報・利用目的・料金条件の変更はなく、文書本文の更新は不要。

## 対応するテスト

- `.maestro/sign-up-consent.yaml`：注意書き、文書の開閉、入力内容の保持、登録時の入力チェック、ログイン画面での非表示。
- `packages/api/src/test/auth.integration.test.ts`：既存の登録・メール確認・重複登録の回帰確認。
- `apps/server/src/public-page.test.ts`：利用規約とプライバシーポリシーの本文配信。
- `bun run test`：全ユーザーストーリーに対応する既存の回帰テスト。

文書表示には [Expo の公式ドキュメント](https://docs.expo.dev/versions/latest/sdk/webbrowser/) に沿った既存の `openBrowserAsync` を使用する。
