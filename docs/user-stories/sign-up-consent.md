# 利用条件を確認して新規登録する

> ステータス: 実装済み。

## ストーリー

新しく利用する人として、登録前に利用規約とプライバシーポリシーを読み、登録操作が同意を意味することを確認して登録したい。

## 動作確認の手順

`bun run dev:server` を起動し、未ログインのブラウザで http://localhost:3000/app/sign-up を開く。

1. 新規登録画面を見る。
   - 「登録する」の直前に「『登録する』を押すと、利用規約およびプライバシーポリシーに同意したものとみなします。」という案内が表示される。
   - 文書名は下線付きのリンクで表示される。
2. 名前を入力してから、利用規約とプライバシーポリシーのリンクをそれぞれ押す。
   - 別のタブで `/terms` と `/privacy` が開き、対応する本文を読める。
   - タブを閉じると新規登録画面のタブに戻り、入力内容が保持される。
   - 文書を読むだけでは登録されない。
   - → [アプリ内で利用条件と個人情報の取り扱いを確認できる](./read-legal-documents.md)
3. 「登録する」から登録を進める。
   - 入力チェックとメール確認へ進む導線が維持される。
   - パスワード欄で Enter キーを押して送信しても、同じ登録処理を行う。
   - → [メールアドレスを確認して利用を始められる](./verify-email.md)
4. ログイン画面に切り替える。
   - 新規登録の同意案内は表示されない。

## データの持ち方

- 登録操作に対する案内を新規登録フォーム（`apps/web/src/components/auth-form.tsx`）に表示する。
- 文書は `target="_blank"` のリンクでサーバーの `/terms` と `/privacy` を開く。
- 同意日時・文書バージョンなどの新しい保存項目や API は追加しない。
- 未ログインで確認できるため、このストーリー専用の seed は不要。
  - 登録済みユーザーでの回帰確認には `packages/db/src/seed/email-verification.ts` の既存コマンドを使う。

## 対応するテスト

- `apps/web/e2e/onboarding.spec.ts`：注意書き、文書のリンク、入力内容の保持、登録時の入力チェック、ログイン画面での非表示。
- `packages/api/src/test/auth.integration.test.ts`：登録・メール確認・重複登録の回帰確認。
- `apps/web/src/server/public-page.test.ts`：利用規約とプライバシーポリシーの本文配信。
- `bun run test`：全ユーザーストーリーに対応する API・サーバーの回帰テスト。
