# 今日の達成を報告すると、ワンちゃんが祝福してくれる

> ステータス: 実装済み

## ストーリー

ログイン中のユーザーとして、今日やるべきことをやったら、すぐに報告したい。
報告するとワンちゃんが出てきて祝ってくれるので、また明日も続けたくなるから。

## 動作確認の手順

`bun run db:seed` でデモデータを入れ、demo@ichiro.app / password123 でログインしておく。

1. メインページで「毎日30分広東語を練習する」のピンクの点々の輪のボタンを押す。
   - 「達成済みにしますか？？」と対象のコミット内容が確認モーダルに出る。詳細ページには遷移しない。
   - この時点では報告されず、お祝い画面も出ない。
2. 「キャンセル」を押す。
   - モーダルが閉じ、未報告の表示と残り件数は変わらない。
3. もう一度点々の輪のボタンを押し、「達成済みにする」を押す。
   - 確認モーダルが閉じ、すぐにお祝い画面が出る。サーバーの応答は待たない。
   - ワンちゃんが下から跳ねて出てきて、耳をパタパタ、しっぽをブンブンさせながらジャンプし続ける。
   - 紙吹雪が舞い、ピンクの光線がゆっくり回る。
   - 出てきたときに軽く2回、着地して画面が揺れるときに強めにバイブが鳴る（iPhone・Android の実機のみ）。
   - 「「毎日30分広東語を練習する」今日も達成！」と、連続達成のタイル（8日）が出る。
   - 「ワン！」の吹き出し、「やったワン！」の見出し、「守った罰金」のタイルは出ない。
   - ワンちゃんを押すと軽くバイブが鳴る。
4. 「つづける」を押す。
   - お祝い画面が閉じる。
   - 「毎日30分広東語を練習する」の点々の輪が、同じ直径36ptのピンクの塗りつぶしと白いチェックに変わる。
   - 「今日の報告 あと◯件」が1つ減る。
5. 「毎日30分広東語を練習する」のカードを押して詳細ページを開く。
   - 「今日は報告ずみ　えらいワン」と表示され、報告ボタンは出ない。
   - 今週の丸のうち、今日の分がピンクになっている。
6. 未報告のコミットメントの詳細ページで「今日の達成を報告する」を押す。
   - メインページから報告したときと同じお祝い画面が出る。
7. 通信できない状態で報告する。
   - お祝い画面は出るが、「報告できませんでした」のアラートが出て、一覧は報告前の状態に戻る。
   - 締め切りを過ぎた日の報告を送ったときも、同じアラートに「締め切りを過ぎたため報告できません」と出る。
   - → [報告できなかった日は罰金が徴収される](./penalty-collection.md)

## データの持ち方

- `report` テーブルに、報告した日（ユーザーの現地日付 `YYYY-MM-DD`）を1行ずつ持つ。
  - 同じコミットメント・同じ日の報告は1件だけ（`commitment_id` と `report_date` のユニーク制約）。
- 報告する前に、締め切りを過ぎた分の罰金を精算する。精算ずみの日（`commitment.settled_through` 以前）には報告できない。
- 報告できるのは、今日がそのコミットメントの報告日のときだけ。
  - 毎日なら期間中の毎日、曜日ごとなら選んだ曜日、月の特定の日なら選んだ日付、1回だけなら実施日。
- 連続達成は、報告日を今日からさかのぼって、途切れずに報告できている回数。
  - 今日がまだ未報告でも、締め切り前なので連続は途切れない。
  - 報告日でない日は数えずに飛ばす。
