# コミットメントを作成できる

> ステータス: 実装済み（罰金の徴収は未実装）

## ストーリー

ログイン中のユーザーとして、目標とそのために毎回やることを宣言したい。
報告の頻度や罰金、チェックしてくれる人を決めておけば、続ける理由ができるから。

## 動作確認の手順

1. メインページの右下のプラスボタンを押す。
   - 「コミットメント作成」ページが開く。
2. 目標とコミット内容を入力する。
   - コミット内容の下の候補（「毎日30分広東語を練習する」「週3でジムに行く」「禁煙する」）を押すと、その文がコミット内容に入る。
3. 結果報告の頻度を選ぶ。
   - 「毎日」「曜日ごと」「月の特定の日」「1回だけ」から1つ選べる。
   - 「曜日ごと」を選ぶと曜日の丸が出て、複数選べる。
   - 「月の特定の日」を選ぶと 1〜31 の日付が出て、複数選べる。
   - 「1回だけ」を選ぶと、下の見出しが「いつまで続ける？」から「実施日」に変わる。
4. いつまで続けるかを選ぶ。
   - 今日より前の日付は選べない。
5. 「罰金を設定する」をオンにする。
   - 金額の欄が出る。−／＋で100円ずつ変えられ、100円より下には下がらない。
   - ¥500・¥1,000・¥3,000 のボタンで金額を選べる。
   - 支払い方法（Apple Pay・Visa •••• 4242）を選ぶ欄が出る。
   - オフに戻すと、金額と支払い方法の欄は消え、罰金なしで保存される。
6. 「誰にチェックしてもらう？」で「友達」を選ぶ。
   - 友達のメールアドレスの欄と、招待メールについての説明が出る。
   - メールアドレスが空のまま宣言すると、エラーが表示されて作成されない。
   - 宣言すると友達に招待メールが届く。
   - → [チェック役の友達に招待メールが届く](./invite-friend.md)
7. 「宣言する」を押す。
   - メインページに戻り、一覧の先頭に新しいコミットメントが出る。
   - お祝い画面が出る。ワンちゃんが下から跳ねて出てきて、紙吹雪が舞い、バイブが鳴って画面が揺れる。
   - 「宣言したワン！」と「「目標」スタート。いっしょにがんばろう」、期間のタイル（〜12/31 のような表示）が出る。
   - 罰金ありなら「罰金」のタイルに金額、罰金なしなら「チェック」のタイルに「自分」か「友達」が出る。
   - 「つづける」を押すとお祝い画面が閉じる。
8. 目標やコミット内容を空のまま「宣言する」を押す。
   - エラーが表示され、作成されない。

## データの持ち方

- `commitment` テーブル
  - `frequency` は `daily`・`weekly`・`monthly`・`once` のどれか。
  - `weekdays`（0 = 日曜〜6 = 土曜）と `month_days`（1〜31）は JSON の配列。頻度に関係ない方も既定値のまま持つので、頻度を切り替えても選択が残る。
  - `start_date` は作成した日（ユーザーの現地日付）。あとから変わらない。
  - `until_date` は終了日。「1回だけ」のときは実施日として使う。
  - `penalty_amount` が null なら罰金なし。100円以上。
  - `payment_method` は罰金ありのときだけ入る（`apple_pay`・`card`）。
  - `checker` は `self`・`friend`。`friend_email` は `friend` のときだけ入る。
  - `friend_email` は小文字にそろえて保存する。
- 友達に送った招待メールは `invitation` テーブルに残す。
- 支払い方法は画面上の選択だけで、実際の決済とはつながっていない。
