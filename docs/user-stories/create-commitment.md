# コミットメントを作成できる

> ステータス: 実装済み

## ストーリー

ログイン中のユーザーとして、毎回取り組む内容を宣言したい。
報告の頻度や罰金を決めて、まずは自分で続ける準備をしたいから。

## 動作確認の手順

リポジトリのルートで `bun run dev:server` を起動し、`bun run --cwd packages/db db:seed:e2e` でデモデータを入れる。
ブラウザで http://localhost:3000/app を開き、demo@ichiro.app / password123 でログインしておく。

1. メインページの右下のプラスボタンを押す。
   - 「コミットメント作成」ページ（`/app/commitments/new`）が開く。
2. コミット内容を入力する。
   - 目標の入力欄は表示されない。
   - コミット内容は高さのある複数行の入力欄に自由に入力でき、長い文章は折り返される。入力欄の下に候補は表示されない。
   - 入力中に Enter キーを押すと、改行を追加せず入力欄から抜ける。日本語入力の変換を確定する Enter では抜けない。
   - 入力内容は保持され、登録は「宣言する」を押すまで行われない。
3. 結果報告の頻度を選ぶ。
   - 「毎日」「曜日ごと」「月の特定の日」「1回だけ」から1つ選べる。
   - 「曜日ごと」を選ぶと曜日の丸が出て、複数選べる。
   - 「月の特定の日」を選ぶと 1〜31 の日付が出て、複数選べる。
   - 「1回だけ」を選ぶと、下の見出しが「いつまで続ける？」から「実施日」に変わる。
4. いつまで続けるかを選ぶ。
   - ブラウザの日付入力で選ぶ。今日より前の日付は選べない。
5. 「罰金を設定する」のスイッチをオンにする。
   - 金額の欄が出る。−／＋で100円ずつ変えられ、100円より下には下がらない。
   - ¥500・¥1,000・¥3,000 のボタンで金額を選べる。
   - 支払い方法を選ぶ欄が出る。Stripe に登録ずみのカードがラジオボタンで並び、最初のものが選ばれている。デモデータでは「Visa •••• 4242」と「Mastercard •••• 4444」が出る。
   - 「＋ 支払い方法を追加」から、その場でカードを登録できる。支払い方法がないまま罰金ありでは宣言できない。
   - → [罰金を払うカードを Stripe に登録できる](./register-payment-method.md)
   - オフに戻すと、金額と支払い方法の欄は消え、罰金なしで保存される。
   - 報告日に報告できなかったときの徴収は、別のストーリーで扱う。
   - → [報告できなかった日は罰金が徴収される](./penalty-collection.md)
6. 「宣言する」を押す。
   - 達成は自分で報告する。チェック者を選択する項目はない。
   - メインページに戻り、一覧の先頭に新しいコミットメントが出る。
   - 「宣言したワン！」のお祝い画面が出る。
   - ワンちゃん、紙吹雪、水色の放射線、期間のタイルが出る。罰金ありなら金額のタイルも出る。「チェック：自分」のタイルは表示しない。
7. お祝い画面の「ホームに戻る」を押す。
   - お祝い画面が閉じ、そのまま一覧に戻る。
8. コミット内容を空のまま「宣言する」を押す。
   - 「コミット内容を入力してください」と出て、作成されない。

## データの持ち方

- `commitment` テーブル
  - 取り組む内容は `content` に保存する。`goal` 列は持たない。
  - `frequency` は `daily`・`weekly`・`monthly`・`once` のどれか。
  - `weekdays`（0 = 日曜〜6 = 土曜）と `month_days`（1〜31）は JSON の配列。頻度に関係ない方も既定値のまま持つので、頻度を切り替えても選択が残る。
  - `start_date` は作成した日（ユーザーの現地日付）。あとから変わらない。
  - `until_date` は終了日。「1回だけ」のときは実施日として使う。
  - `penalty_amount` が null なら罰金なし。100円以上。
  - `payment_method_id` は罰金を引き落とす支払い方法（`payment_method` テーブルの行）。罰金ありのときだけ入る。
  - `time_zone` は作成したブラウザのタイムゾーン。罰金の締め切りの判定に使う。
  - `settled_through` は前日にする。罰金は今日の分から精算の対象になる。
