# メインページでコミットメントを一覧できる

> ステータス: 実装済み

## ストーリー

ログイン中のユーザーとして、自分が宣言したコミットメントをひと目で見たい。
今日まだ報告していないものが分かれば、忘れずに達成を報告できるから。

## 動作確認の手順

リポジトリのルートで `bun run dev:server` を起動し、`bun run --cwd packages/db db:seed:e2e` でデモデータを入れる。
ブラウザで http://localhost:3000/app を開き、demo@ichiro.app / password123 でログインしておく。

1. メインページ（`/app`）を開く。
   - 左上にロゴ、右上にアカウントのボタン（写真か人型アイコン）、右下にプラスボタンがある。
   - ロゴの下に「今日の報告 あと◯件」が1行で表示される。すべて報告ずみなら「今日はぜんぶ報告ずみ」、今日が報告日のものがなければ「今日の報告はありません」になる。
   - スマートフォンの幅では1カラムで表示され、PC の幅では最大 440px の列が中央に寄る。
2. コミットメントの一覧を見る。
   - 新しく作ったものから順に並ぶ。デモデータでは「毎日30分広東語を練習する」「週3でジムに行って、筋トレ45分と有酸素運動20分をやる」「禁煙する」の順。
   - 各カードに、実施期間（9/1〜12/31 のような表示）、コミット内容が上から順に左揃えで出る。
   - カードの角丸は半径36px で表示され、右端のチェブロンは表示されない。
   - コミット内容は最大3行表示し、それより長いと「…」で切れる。
   - 今日が報告日で未報告のものには、中が空の水色の点々の輪が出る。報告ずみのものは水色の塗りつぶしに白いチェックになる。今日が報告日でないものにはどちらも出ない。
   - 未報告・報告ずみの丸は直径36px で、影は付かない。未報告のボタンの押せる範囲は44px 四方を保つ。
   - 未報告の丸を押すと、アプリ内の確認ダイアログ「達成済みにしますか？？」が出る。詳細ページには移らない。
   - → [今日の達成を報告する](./report-achievement.md)
3. カードを押す。
   - カード全体が詳細ページへのリンクになっており、`/app/commitments/<id>` の詳細ページが開く。
   - → [コミットメントの詳細を見て、途中で設定を変えられる](./edit-commitment.md)
4. 右下のプラスボタンを押す。
   - コミットメント作成ページ（`/app/commitments/new`）が開く。
   - 作成・戻る・アカウントなどのボタンに下側の影や沈み込む動きがなく、マウスを重ねたときや押している間は色が変わる。
   - → [コミットメントを作成できる](./create-commitment.md)
5. 右上のアカウントのボタンを押す。
   - アカウントの画面（`/app/account`）が開く。
   - → [アカウントを管理できる](./profile-sheet.md)
6. コミットメントがひとつもないアカウントでログインする。
   - 一覧の代わりに、ワンちゃんと「まだ目標がないワン。右下の＋から宣言しよう。」が表示される。

## データの持ち方

- `commitment` テーブルに1件ずつ持つ。`user_id` で持ち主を決める。
  - 一覧は `created_at` の新しい順。同じミリ秒に作られたものは、あとから入れた行を先にする。
- 今日が報告日か（`dueToday`）、今日報告したか（`reportedToday`）、連続達成（`streak`）は保存せず、`report` テーブルから毎回計算する。
  - 「今日」はユーザーの現地日付。ブラウザが `YYYY-MM-DD` で送り、サーバーは自分の UTC 日付から1日を超えてずれた値を受け付けない。
