# ホーム画面のアプリアイコンを選べる

> ステータス: 実装済み

## ストーリー

利用者として、青・紫・ピンクのロゴから好きなものを選び、携帯のホーム画面で自分好みのアイコンを使いたい。

## 動作確認の手順

1. 新規インストールしたネイティブアプリを起動する。
   - デフォルトは青のロゴで表示される。
2. `packages/db/src/seed/run.ts` の確認用アカウントでログインし、右上のプロフィールからアカウント画面を開く。
   - 「アプリアイコン」に青・紫・ピンクの画像が表示され、青が選択されている。
3. 紫を選択し、OSの案内が表示された場合は閉じてホーム画面に戻る。
   - アプリアイコンが紫に変わる。Androidではランチャーによって反映に時間がかかる場合がある。
   - アイコンから同じアプリを起動できる。
4. アプリを終了して再起動し、アカウント画面を開く。
   - 紫の選択が保持される。
5. ピンクを選び、同様にホーム画面で確認する。続けて青に戻す。
   - それぞれの画像に変わり、青に戻すと標準アイコンになる。
   - 選択中の色を再度押しても状態は変わらない。
   - 変更中は他の色を押せず、失敗時はエラーが表示される。
6. コミットメント一覧と詳細を開く。
   - アプリ内の配色、ロゴ、プロフィール写真は変わらない。
   - → [コミットメント一覧](./commitment-list.md)
   - → [プロフィール](./profile-sheet.md)

## データの持ち方

- 3枚の提供画像を `apps/native/assets/images/app-icons/` に同梱する。
- 選択状態はOSのアイコン設定から読み取る。サーバーには保存せず、端末間で同期しない。
- iOSでは標準アイコンを青、代替アイコンを紫・ピンクとしてビルド時に登録する。
- Androidでは3色のactivity-aliasを登録し、選択した起動口だけを有効にする。
- APIとDBは変更しない。確認用seedは既存コマンドを利用する。
  - `bun run db:seed -- --url file:/absolute/path/to/local.sqlite --skip-migrations`
- 料金、契約、個人情報の取り扱いは変わらないため、利用規約・プライバシーポリシー・特商法表記の変更は不要。

## 対応するテスト

- `.maestro/app-icon.yaml`：3色の切り替えと再起動後の保持をネイティブアプリで確認する。
- ホーム画面の画像とアイコンからの起動はiOS Simulatorで確認する。
- `bun run test`：既存ユーザーストーリーに対応するAPI・サーバー・環境設定の回帰テスト。
- `bun run check-types`：ネイティブ画面を含む型チェック。
